# Terlik Sağa Kayma Yasası

Ev içi hukukun en ihmal edilmiş maddesi budur. Terlik, sahibi fark etmeden, daima sağa kayar. Bu bir görüş değildir. Bu bir katsayıdır.

Bu depo, o katsayıyı ölçen, tutanak basan ve kimseyi tatmin etmeyen resmi bir uygulamadır. Anlamı yoktur. Çalışır. Patates içermez. Asansör de içermez. Buzdolabı ışığı sendikaya üyelik başvurusu reddedilmiştir.

## Neden var

Çünkü bir gece terlik sola gitti sanıldı. Sabah ölçüldü. Sağa gitmişti. Bilim sustu. Yasa konuştu.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Fayans parlaklığı isteğe bağlıdır.

```bash
python3 terlik_yasasi.py --ayak sag --dakika 14 --zemin fayans
python3 terlik_yasasi.py --ayak sol --dakika 3 --zemin hali --gizli
```

`--gizli` bayrağı, yasanın dipnotunu açar. Dipnotu yüksek sesle okumayın. Komşu duyar, zemin değişir.

## Madde 7/B

1. Terlik, yalnız bırakıldığında sağa kayma eğilimi gösterir.
2. Sol ayak itiraz edebilir. İtiraz, tutanağa geçer, sonucu değiştirmez.
3. Halı, fayansın temyizidir. Kaymayı yavaşlatır, iptal etmez.
4. İki terlik birden kayarsa bu evlilik değil, fiziktir.

## Örnek çıktı

Program size bir dosya numarası, bir kayma katsayısı ve bir hüküm verir. Hüküm bağlayıcı değildir. Terlik bağlayıcıdır.

## Lisans

Ev içi kamu malı. Çalınabilir. Geri gelmez. Sağa kayar.
